# Query & Path
Si la valeur sert à identifier directement une ressource, on utilise généralement le Path. Si elle sert à filtrer, rechercher, trier ou contrôler la manière dont on récupère une collection, on utilise généralement Query.
---------------
# Header
Un header est une information supplémentaire envoyée avec la requête HTTP

* Accept
Indique au serveur quel type de réponse le client souhaite.
-> Accept: application/json

* Content-Type
Indique le format des données envoyées dans le body.
-> Content-Type: application/json

* Authorization
Sert généralement à transmettre des informations d'authentification.
-> Authorization: Bearer eyJhbGciOi...

* User-Agent
Permet généralement d'indiquer quel client effectue la requête
-> User-Agent: Mozilla/5.0
--> user_agent: str = Header() # forcer le header
--> user_agent: str | None = Header(default=None) # le header peut être nul
--> user_agent: str | None = Header(default=None, alias="User-Agent")

from typing import Annotated
from pydantic import BaseModel, Field

class OldProductCreate(BaseModel):
    name: str = Field(min_length=2, max_length=100)
    price: float = Field(ge=0)
    quantity: int = Field(ge=0)

ProductName = Annotated[
    str,
    Field(min_length=2, max_length=100)
]

PositivePrice = Annotated[
    float,
    Field(ge=0)
]

PositiveQuantity = Annotated[
    int,
    Field(ge=0)
]

class ProductCreate(BaseModel):
    name: ProductName
    price: PositivePrice
    quantity: PositiveQuantity


class ProductPatch(BaseModel):
    name: ProductName | None = None
    price: PositivePrice | None = None
    quantity: PositiveQuantity | None = None

* pagination:
# offset + limit = mécanique
offset → combien je saute
limit  → combien je prends
page = (offset // limit) + 1
--
# page + page_size = abstraction
offset = (page - 1) * page_size
limit = page_size
--------------------------
total_in_db = 73
page = 3
page_size = 20

* offset
offset = (page - 1) * page_size
       = (3 - 1) * 20
       = 40
--> offset = 40

* total_pages
total_in_db/page_size
73 éléments
20 éléments/page
73/20 = 3,65 => 4
--> total_pages = 4
Page 1 → 1 à 20
Page 2 → 21 à 40
Page 3 → 41 à 60
Page 4 → 61 à 73
