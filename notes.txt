# Query & Path
Si la valeur sert à identifier directement une ressource, on utilise généralement le Path. Si elle sert à filtrer, rechercher, trier ou contrôler la manière dont on récupère une collection, on utilise généralement Query.
---------------
# Header
Un header est une information supplémentaire envoyée avec la requête HTTP

* Accept
Indique au serveur quel type de réponse le client souhaite.
-> Accept: application/json

* Content-Type
Indique le format des données envoyées dans le body.
-> Content-Type: application/json

* Authorization
Sert généralement à transmettre des informations d'authentification.
-> Authorization: Bearer eyJhbGciOi...

* User-Agent
Permet généralement d'indiquer quel client effectue la requête
-> User-Agent: Mozilla/5.0
--> user_agent: str = Header() # forcer le header
--> user_agent: str | None = Header(default=None) # le header peut être nul
--> user_agent: str | None = Header(default=None, alias="User-Agent")
